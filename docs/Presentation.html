CORE CPU ARCHITECTURE

Registers, ALU, & Status Flags (PSW)

REGISTER FILE
  • PC: Program Counter (16-bit address pointer)
  • IR: Instruction Register (holds current opcode)
  • ACC: Accumulator (primary math register)
  • R0–R3: General purpose registers (hold lane queues)
  • SP: Hardware Stack Pointer (0x8FFF)
  • CLOCK: Total executed clock cycles counter
ALU & STATUS FLAGS
  • Operations: ADD, SUB, MUL, DIV, AND, OR, XOR, NOT, CMP, INC, DEC
  • Safe Division: Division by zero handled safely with V flag
  • Status Flags: Zero (Z), Carry (C), Negative (N), Overflow (V)
EXECUTION CYCLE

Five-Stage Instruction Cycle

Every instruction executes through five observable hardware stages:

1. FETCH: PC -> Address Bus -> Memory -> IR; PC <- PC + 1
2. DECODE: Control Unit decodes opcode; asserts RegWrite, MemRead, ALUOp micro-signals
3. EXECUTE: ALU executes math/logic operation or evaluates branch conditions
4. MEMORY: Data memory read/write or I/O port read/write across Data Bus
5. WRITE BACK: Commit computed result into destination register Rd
I/O & INTERRUPT SUBSYSTEM

Memory-Mapped I/O & Emergency Preemption

MEMORY-MAPPED I/O MAP
  • 0xF000 - 0xF003: North, South, East, West queue sensors
  • 0xF010 - 0xF013: Signal actuators (0=Red, 1=Yellow, 2=Green)
  • 0xF020: Emergency status approach indicator
  • 0xF021: Emergency acknowledge & clear
INTERRUPT SERVICE ROUTINE (ISR)
  • Ambulance asserts hardware IRQ on Vector 0x0004
  • CPU pushes PC and FLAGS to hardware stack (SP)
  • CPU transfers PC to 0x0200 (ISR entry)
  • Sets all lights RED, turns emergency lane GREEN
  • Executes IRET to restore PC and FLAGS
